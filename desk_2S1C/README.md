# 机械手上位机 - 2S1C v2.0

基于 PyQt6 的机械手控制上位机软件，兼容ESP32-P4下位机通信协议。

## 主要改进

### 修复的协议问题 (v1.0 → v2.0)

| 问题 | v1.0 (错误) | v2.0 (修正) |
|------|-------------|-------------|
| **字节序** | 小端 `<f` | **大端** `>h, >i` |
| **传感器数据** | float | **int16** |
| **舵机位置** | float | **int32** |
| **电机直控** | float | **uint16/int16** |
| **数据模型** | 简单列表 | **HandModel** |
| **串口超时** | 默认 | **0.1秒** |
| **线程架构** | 单一 | **RX/TX分离** |

## 功能特性

### 基本控制
- **串口连接**: 921600波特率 (与参考实现一致)
- **控制模式切换**: 关节角度 / 电机直控
- **PID使能控制**
- **系统控制**: 启动/停止/复位

### 关节控制
- **21路关节独立控制**: 每个关节 -90° ~ +90°
- **实时滑条跟随**: 拖动时实时发送
- **9种预设手势**: 张开、握拳、握持、指向、剪刀手、OK、点赞、捏取、放松
- **批量发送/归零/读取当前角度**

### 电机直控
- **22路电机独立控制**
- **单圈模式**: 0-4095
- **多圈绝对位置模式**: -30719~30719
- **批量发送/全部置中**

### 状态监控
- **22路舵机在线状态**: 实时显示
- **多圈绝对位置**: 实时显示
- **故障检测**: 过载保护、反绕释放保护

## 通信协议细节

### 字节序修正 (关键)

| 数据类型 | 格式 | 说明 |
|----------|------|------|
| 传感器角度 | `>h` (大端int16) | 原始编码器值 |
| 舵机多圈位置 | `>i` (大端int32) | 多圈绝对位置 |
| 舵机单圈位置 | `>h` (大端int16) | 0-4095 |
| 遥测速度/负载 | `>h` (大端int16) | 有符号值 |
| 关节目标角度 | `<f` (小端float) | 度数 |
| 标定零位 | `<f` (小端float) | 原始值 |

### 帧格式
```
[0xFE] [LEN] [CMD] [PAYLOAD...] [0xFF]
```

### 下行命令
- `0xCC` - 启动控制 (START)
- `0xCD` - 停止控制 (STOP)
- `0xCE` - 复位 (RESET)
- `0xCB` - 关节角度控制 (21路float)
- `0xD0` - 电机直控单圈 (22路uint16)
- `0xD3` - 电机直控绝对位置 (22路int16)

### 上行数据
- `0x01` - 传感器数据 (21路int16)
- `0x03` - 舵机多圈角度 (22路int32 + 在线标志)
- `0x05` - 舵机遥测 (速度/负载/电压/温度)
- `0x07` - 过载故障位图
- `0x08` - 反绕释放故障位图

## 使用说明

### 连接硬件
1. 使用 USB 线连接 ESP32-P4 控制板
2. 在上位机选择对应的串口
3. 点击"连接"按钮
4. 连接成功后，"启动控制"按钮变为可用

### 控制机械手
1. 点击"启动控制"使能电机输出
2. 选择控制模式:
   - **关节角度模式**: 通过21路关节角度控制手势
   - **电机直控模式**: 直接控制22路电机位置
3. 选择预设手势或手动调节
4. 点击"停止控制"停止输出

### 故障排查
- **舵机显示红色**: 舵机离线，检查硬件连接
- **故障状态显示**: 查看是否触发过载或反绕保护
- **无法连接**: 检查串口是否被其他程序占用
