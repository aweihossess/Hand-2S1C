# 双电机MCP关节控制 - Arduino项目

## 项目结构

```
arduino/
├── MCP_DualMotor_Calibration/
│   └── MCP_DualMotor_Calibration.ino    # 主程序
├── motor_driver.h                        # 电机驱动库（可选）
└── encoder_driver.h                      # 编码器读取库（可选）
```

## 硬件要求

### 必需硬件
- **Arduino板**: Uno/Mega/Leonardo 或 ESP32
- **电机**: 2个带磁编码器的伺服/步进电机
- **磁编码器**: 2个14位SPI磁编码器（如AS5048A、AS5047P）

### 引脚定义（可修改）
```cpp
// 电机1
#define MOTOR1_PIN_EN   5    // 使能
#define MOTOR1_PIN_STEP 6    // 步进
#define MOTOR1_PIN_DIR  7    // 方向

// 电机2
#define MOTOR2_PIN_EN   8    // 使能
#define MOTOR2_PIN_STEP 9    // 步进
#define MOTOR2_PIN_DIR  10   // 方向

// 编码器SPI
#define ENCODER1_CS     A0   // 编码器1片选
#define ENCODER2_CS     A1   // 编码器2片选
```

## 控制原理

### 物理模型
```
MCP关节有两个自由度：
- Fe (Flexion/Extension): 屈曲/伸展（弯曲）
- AA (Abduction/Adduction): 外展/内收（侧向）

双电机耦合关系：
  电机1位置 = Fe + AA
  电机2位置 = Fe - AA
```

### 零点标定流程
1. 关闭力矩，进入自由旋转模式
2. 手动调整至绳索拉紧的机械零位（Fe=0, AA=0）
3. 记录当前编码器值为零点基准
4. 保存到EEPROM（掉电不丢失）

## 串口命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `ZERO1` | 标定电机1零点 | `ZERO1` |
| `ZERO2` | 标定电机2零点 | `ZERO2` |
| `ZERO_ALL` | 同时标定双电机 | `ZERO_ALL` |
| `FE:xx` | 设置屈曲角度 | `FE:30` (0-90°) |
| `AA:xx` | 设置外展角度 | `AA:15` (0-45°) |
| `POS` | 查询当前位置 | `POS` |
| `TORQUE:0` | 关闭力矩 | `TORQUE:0` |
| `TORQUE:1` | 使能力矩 | `TORQUE:1` |
| `SAVE` | 保存零点到EEPROM | `SAVE` |
| `STATUS` | 显示状态 | `STATUS` |

## 使用方法

### 1. 首次使用标定（上位机方式）
```
1. 连接上位机，打开"双电机MCP关节标定与控制"面板
2. 点击【进入标定模式】- 力矩自动关闭，进入自由模式
3. 使用【+10°/-10°】按钮微调电机1和电机2位置
4. 观察实时编码器角度，调整至接近0°（拉紧状态）
5. 点击【确认标定零点】- 自动标定并保存到EEPROM
6. 标定完成！可使用Fe/AA滑块控制关节
```

### 2. 首次使用标定（手动串口方式）
```
1. 上电后串口输入 STATUS 查看状态
2. 输入 TORQUE:0 关闭力矩，进入自由模式
3. 输入 MOVE1:10 / MOVE1:-10 微调电机1位置
4. 输入 MOVE2:10 / MOVE2:-10 微调电机2位置
5. 手动调整机构至零位（绳索拉紧、Fe=0、AA=0）
6. 输入 ZERO_ALL 标定双电机零点
7. 输入 SAVE 保存到EEPROM
8. 输入 TORQUE:1 使能力矩
9. 标定完成！
```

### 2. 控制关节
```
设置 Fe=30°, AA=15°:
  FE:30
  AA:15

查看当前位置:
  POS
```

### 3. 与上位机配合
- 使用上位机"双电机MCP关节标定与控制"面板
- 点击【进入标定模式】按钮开始标定
- 使用微调按钮（+10°/-10°）调整电机位置
- 观察实时编码器角度显示，调整至接近0°
- 点击【确认标定零点】保存零点
- 使用 Fe/AA 滑块控制关节角度

## 代码功能模块

### 核心函数
- `readEncoder()`: 读取14位磁编码器值（SPI）
- `calibrateMotor1/2()`: 单电机零点标定
- `calibrateDualMotor()`: 双电机同时标定
- `setMCPPosition()`: 设置Fe/AA角度
- `saveZeroToEEPROM()`: 零点持久化存储
- `loadZeroFromEEPROM()`: 零点自动加载

## 注意事项

1. **编码器选择**: 确保使用14位磁编码器，与代码中的`ENCODER_MAX=16384`匹配
2. **零点保存**: 标定后自动保存到EEPROM，下次上电自动加载
3. **耦合关系**: 如果机械结构不同，需修改`setMCPPosition()`中的公式
4. **安全**: 首次测试时保持低速度，确保机构不会损坏

## 上位机通信

### 串口配置
- 波特率: 921600
- 数据位: 8
- 停止位: 1
- 校验: 无

### 协议格式
```
[命令]\n
示例:
  ZERO_ALL\n
响应:
  [标定] 双电机零点已同时记录
```
