# 线性系统判别实验

## 目标

这个实验用于判断手指系统在不同初始姿态 `S_i_0` 附近是否可以近似看成局部线性系统。实验记录每个初始姿态下，单个电机的小位移扰动对绳张力、关节角度和电机反馈的影响：

```text
Δy = S_i_j_k - S_i_0
```

其中 `i` 是初始状态序号，`j` 是被扰动电机，`k` 是扰动量和重复次数。

## 控制流程

1. 从界面读取五个电机的初始 ABS 目标 `p0=[p00,p01,p02,p03,p04]`，切到 `direct` 并将 M00-M04 作为一组同时下发。该阶段不再发送关节 `degree` 目标，也不启动力反馈张紧。
2. 只使用电机位置判断“到位”：M00-M04 实际 ABS 与各自目标的误差绝对值都不超过 `10 counts`。到位后连续停留 `1.0 s`（界面的 `到位停留s` 可调）并记录 `perturb` 最终点；随后重新下发同一个五路电机目标，在目标不变的情况下额外保持 `1.0 s`，期间继续每 `100 ms` 记录，之后才下发下一个位置。额外保持阶段只计时，不要求电机速度为零，也不重新进行位置稳定判定，但安全保护仍然生效。
3. 从每次位置命令发出后到停留结束，以 `100 ms` 间隔持续记录五电机 ABS/速度、四关节角和五路绳张力。角度波动、力波动和电机速度只记录到 CSV，不参与到位或停留完成判断。
4. 记录基准状态 `S_i_0`：四个关节角、五路绳张力以及五个电机的实际 ABS。后续扰动以这一帧的实际 ABS 作为 `baseline_abs`，而不是只使用下发目标。
5. 保持 `direct` 模式，对每个电机按固定序列发送扰动。扰动量 `delta_counts` 是被测电机相对 `S_i_0` 中电机反馈 `baseline_abs` 的差值；每个序列点都会同时给 M00-M04 发送目标：
   - 被测电机：`baseline_abs + delta_counts`；
   - 其它电机：各自保持在 `baseline_abs`。
6. 默认序列为 `0, +50, +100, +50, 0, -50, -100, -50, 0`：
   - 每个序列点只要求五个电机到位并完成停留，不强制关节角或力恢复到原始 `S_i_0`；
   - 每个序列点在到位停留完成时记录一行 `perturb`，移动和停留过程另按 100 ms 记录 `perturb_trace`；
   - `0` 点也会记录，用来观察回差路径中的“回到指令零扰动”是否真的回到原物理状态。
7. 初始位置和扰动等待过程都会做安全检查：任意电机反馈偏离本次目标超过 `300 counts`、任意电机距离 `±30719` 位置限位小于 `500 counts`，或任意绳张力紧到 `-140 N` 以下，实验立即停止。
   停止时会上位机清空尚未发送的 Encoder/Servo 命令队列，并优先发送 `stop`、`tensionbias clear`、`tension off`。
8. 当前初始位置的全部扰动完成后，进入下一组初始位置。

## 界面参数

主窗口新增 `线性系统判别实验` 区域：

- `初始ABS(M00→M04)`：按 M00、M01、M02、M03、M04 的顺序输入 5 个整数位置，电机间用分号分隔，例如 `3500;4500;4000;3000;2000`。多组初始位置用 `|` 分组，例如 `3500;4500;4000;3000;2000 | 3600;4600;4100;3100;2100`。也支持显式写成 `M00=3500;M01=4500;M02=4000;M03=3000;M04=2000`。
- `电机`：扰动电机列表，默认 `M00,M01,M02,M03,M04`。
- `扰动counts`：默认 `0,50,100,50,0,-50,-100,-50,0`。
- `重复`：默认 `3`。
- `到位停留s`：默认 `1.0`；表示五个电机到达目标 ABS 后，停留多久才执行下一个位置。
- `超时s`：默认 `40.0`。

线性实验的输入是 M00-M04 五个电机的 ABS 位置，输出仍记录 J00-J03 四个关节角与 M00-M04 五路绳张力。

## 数据文件

实验数据写入：

```text
run_data/linearity_YYYYmmdd_HHMMSS.csv
```

每行包含：

- 实验元数据：`experiment_id`、`phase`、`state_i`、`state_target`（输入的 M00-M04 初始 ABS）、`motor_j`、`delta_counts`、`repeat_id`、`trial_index`、`sequence_step`。
- 到位停留和观测信息：`stable_hold_s`（字段名为了兼容旧 CSV，现表示到位后已停留时间）、`max_joint_delta_deg`、`max_force_delta_n`、`max_motor_speed`。后三项只是记录值，不是通过条件。
- 基准索引：`baseline_sample_index`、`baseline_label`。
- 原始状态：M00-M04 张力、J00-J03 角度、M00-M04 servo abs/speed/load/current/online。
- 相对基准差值：`delta_joint_j00_deg`、`delta_tension_m00_n`、`delta_servo_m00_abs` 等。
- 本次 direct 目标和反馈误差：`target_servo_m00_abs`、`target_error_m00_counts` 等。

`phase=baseline` 表示 `S_i_0`，`phase=perturb` 表示序列扫描中的某个点；当 `delta_counts=0` 时，它表示当前路径下指令回到 baseline abs 后的状态。

`phase=baseline_trace` 和 `phase=perturb_trace` 是移动及到位停留过程中的 `100 ms` 连续数据；现有 CSV 后处理只使用 `phase=perturb` 的到位停留完成点，不会把过渡数据混入静态影响系数与回差分析。

## 判别方法

对每个初始姿态 `S_i_0` 分组后，可以检查：

- 比例性：同一方向上 `Δy(+100)` 是否约等于 `2 * Δy(+50)`。
- 路径回差：`0 -> +50 -> +100 -> +50 -> 0` 中第二次 `+50` 和第一次 `+50` 是否相同，回到 `0` 后是否接近 baseline。
- 奇对称：负方向 `-50/-100` 是否与正方向呈近似反向响应。
- 重复性：同一个 `(S_i, motor_j, delta_counts, sequence_step)` 的 3 次重复是否接近。
- 局部线性：在每个 `S_i` 附近拟合 `Δy = A_i Δu`，观察残差。
- 全局线性：比较不同 `S_i` 下得到的 `A_i` 是否接近。

如果比例性和奇对称都差，通常说明摩擦、回差、绳松紧状态或耦合非线性明显；如果单个 `S_i` 内近似线性但不同 `S_i` 的 `A_i` 差异大，则系统更适合按姿态做局部线性模型。

## 当前实验现象

在早期 `linearity_20260708_190704.csv` 中，第一个初始状态 `S01_0` 已经完成 baseline、`M00 +50 counts` 和 `M00 +100 counts` 两个扰动记录，但随后在强制 `return_baseline` 阶段超时：

```text
baseline:
M00 abs = 1073
J00 = 14.722 deg
J01 = 17.688 deg
M00 tension = -16.6 N
M03 tension = -48.2 N

M00 +50:
delta_joint_j00 = +0.857 deg
delta_tension_m00 = -2.8 N
delta_tension_m03 = +3.5 N

M00 +100:
delta_joint_j00 = +1.626 deg
delta_joint_j01 = +0.945 deg
delta_tension_m00 = -4.0 N
delta_tension_m03 = +5.1 N
```

当时回基准判据为：

```text
角度差 <= 1.0 deg
力差 <= 5.0 N
保持 1.5 s
超时 40 s
```

`M00 +100` 后已经超过或贴近该判据，尤其 `J00` 偏差约 `1.626 deg`、`M03` 张力偏差约 `5.1 N`。程序随后向 M00-M04 发送 baseline 时记录的 servo abs 位置，但 40 s 内仍未回到 `S01_0` 附近，因此停止。

这个现象说明：**对当前手指系统，direct 回到同一个 servo abs 位置不一定能恢复同一个物理状态**。可能原因包括：

- 绳传动摩擦和回差。
- 扰动后绳张力残余没有释放。
- 关节和腱绳之间存在耦合，单动 M00 会影响 J01、M03 张力等其它输出。
- 电机位置闭环回到相同编码位置，但绳长、接触状态和关节受力路径已经不同。

因此这个实验本身已经给出一个重要判断：系统至少在 `S01` 附近不是理想线性、无回差系统。当前流程已经改为连续路径记录，不再强制每次回到原始物理状态，而是直接记录：

```text
0, +50, +100, +50, 0, -50, -100, -50, 0
```

这样可以把“同一指令点在不同路径下得到不同物理状态”直接作为回差/非线性数据保存下来。

### 2026-07-08 断绳相关现象

在 `linearity_20260708_192032.csv` 中，实验停在 43 行。该次数据暴露出一个更严重的问题：旧版扰动命令只发送当前被测电机，例如 `direct; m3 816`，没有同时把其它电机固定在 `S_i_0` 的 baseline abs。结果在只测试 M00/M01/M02/M03/M04 的过程中，M02 和 M03 持续大幅漂移：

```text
baseline:
M02 abs = 1537
M03 abs = 766
M03 tension = -64.8 N

第 2 行，仅发送 M00 delta=0:
M02 abs = 425,  delta_servo_m02 = -1112 counts
M03 abs = 1883, delta_servo_m03 = +1117 counts

第 29 行，开始测试 M03:
M02 abs = -2222, delta_servo_m02 = -3759 counts
M03 abs = 4536,  delta_servo_m03 = +3770 counts
M03 tension = -122.0 N

第 43 行，测试 M04 delta=-50:
M02 abs = -4170, delta_servo_m02 = -5707 counts
M03 abs = 6517,  delta_servo_m03 = +5751 counts
```

这说明当 `tension off` 且只给单个电机发 direct 目标时，非被测电机可能在腱绳负载下背驱或漂移，实际扰动量远远超过设定的 `50/100 counts`，从而造成过紧、松绳或断绳风险。当前代码已改为每个扰动点同时发送 M00-M04 的 direct 目标：被测电机取 `baseline_abs + delta_counts`，其它电机保持 `baseline_abs`；同时增加 `300 counts` 目标偏离保护和 `-140 N` 过紧保护。
