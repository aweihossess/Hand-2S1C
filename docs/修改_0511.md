# 0511 修改记录：舵机目标位置限幅

## 修改位置

文件：

`ESP32-P4/ServoBoardMain/src/control/ControlOutputBuilder.cpp`

函数：

`clampServoPos(int32_t value)`

## 修改内容

将舵机目标位置的限幅范围改为 `-4096 ~ 4096`：

```cpp
int16_t clampServoPos(int32_t value)
{
    if (value > 4096) return 4096;
    if (value < -4096) return -4096;
    return (int16_t)value;
}
```

该函数会在控制输出阶段被调用，用于限制最终下发到舵机通信层的目标位置。

## 数据流影响

目标角度下发后的主要链路为：

```text
上位机目标角度
  -> sharedData.targetAngles
  -> commandSnapshot.targetAngles
  -> localTargets
  -> ControlSolver.compute(...)
  -> outPulses
  -> clampServoPos(outPulses[jointIndex])
  -> ServoTargetBatch
  -> servoTargetQueue
  -> ServoCommunicationTask
  -> 舵机同步写
```

因此，本次修改影响的是 `outPulses` 转成舵机目标位置之后的最终限幅结果。

## 影响范围

直接影响：

- `ControlTask.cpp` 中关节模式输出：`clampServoPos(outPulses[jointIndex])`
- `ControlTask.cpp` 中异常/保持逻辑：对 `holdPos` 的限幅
- direct motor 绝对目标模式中使用 `clampServoPos(...)` 的路径
- `expandSingleTurnTargetNearCurrent(...)` 的返回值限幅

间接影响：

- 舵机目标不会再超过 `4096` 或低于 `-4096`
- 多圈大范围位置命令会被截断到该范围内
- 如果原控制逻辑依赖 `-30719 ~ 30719` 的多圈范围，需要重新评估运动范围是否足够

## 注意事项

当前文件中 `clampServoPos` 上方注释仍描述为 signed multi-turn range。若确认后续长期使用 `-4096 ~ 4096`，建议同步更新注释，避免误以为仍是大范围多圈限幅。
