# 五腱四关节当前控制逻辑

> 最终版本说明：本文件的历史细节已由 `final_five_tendon_control_theory_20260719.md` 取代。当前默认配置为 `Kp=0.70`、`Ki=0.02 1/s`、`rblend=0`、`pblend=0.25`、电机有限差分 `80 counts/10 ms`。请以最终报告和当前代码为准。

本文档对应 `codex/five-tendon` 分支当前实现，用于说明五根腱绳、四个关节角的运行时控制、零空间张力分配、安全保护以及自动实验流程。

主要代码位置：

- 固件控制器：`ESP32-P4/ServoBoardMain/src/control/ControlSolver.cpp`
- 控制参数：`ESP32-P4/ServoBoardMain/src/control/ControlSolverConfig.h`
- 10 ms 控制任务：`ESP32-P4/ServoBoardMain/src/control/ControlTask.cpp`
- 上位机与张力分配：`desktop/force_sensor_monitor.py`
- ESP32-S3 磁编码器采集：`ESP32-S3/System/`

## 1. 系统结构

```text
目标关节角 q_target
        │
        ▼
ESP32-P4 参考轨迹限速 q_ref
        │
        ├──────────────┐
        ▼              ▼
R 前馈             P + I 角度反馈
        │              │
        └──────┬───────┘
               ▼
        Q = R R⁺ 任务投影
               │
               ├──────────────┐
               ▼              ▼
        关节任务位移       上位机 αn 预紧偏置
               └──────┬───────┘
                      ▼
             绝对电机目标 x_requested
                      │
                      ▼
              每周期有限差分限幅
                      │
                      ▼
                 五路飞特舵机
```

数据链路：

1. ESP32-S3 读取 J00～J03 磁编码器，向 ESP32-P4/上位机提供角度。
2. ESP32-P4 以 10 ms 周期运行角度控制器并下发五路电机目标。
3. 上位机读取五路拉力传感器，以 100 ms 周期调整零空间预紧量 `α`。
4. 上位机可以连续记录角度、电机、拉力、控制目标和实验事件。

## 2. 符号

| 符号 | 维度 | 含义 |
|---|---:|---|
| `q_target` | 4×1 | 上位机请求的最终关节角 |
| `q_ref` | 4×1 | 固件有限步长后的参考关节角 |
| `q_entry` | 4×1 | degree 控制启动时记录的关节角 |
| `q_fb` | 4×1 | 滤波后的实测关节角 |
| `e_q` | 4×1 | 角度误差 `q_ref - q_fb` |
| `x_entry` | 5×1 | degree 控制启动时的五电机 ABS |
| `R` | 5×4 | 识别得到的腱长/关节角前馈矩阵，单位 mm/rad |
| `P` | 5×4 | 角度反馈方向矩阵，单位 mm/rad |
| `Q` | 5×5 | 任务空间投影矩阵 `R R⁺` |
| `n` | 5×1 | 单位化零空间向量 |
| `α` | 标量 | 零空间预紧坐标 |
| `c` | 标量 | 200 counts/mm |

所有控制公式中的关节角均换算为弧度。

## 3. 当前矩阵

### 3.1 前馈矩阵 R

当前固件中的拟合矩阵为：

```text
R = [
  [ 3.6109,  3.4232,  0.0000,  0.0000],
  [-2.9767,  4.0643,  0.0000,  0.0000],
  [-1.9980, -1.3476,  2.9110,  0.0000],
  [ 2.5066, -1.5569,  0.0000,  3.6078],
  [ 0.0000, -3.8985, -4.3955, -3.3443]
]
```

行对应 M00～M04，列对应 J00～J03。

### 3.2 反馈矩阵 P

```text
P = [
  [ 4.3,  5.9,  0.0,  0.0],
  [-4.3,  5.9,  0.0,  0.0],
  [-1.2, -3.0,  6.0,  0.0],
  [ 1.2, -3.0,  0.0,  4.8],
  [ 0.0, -6.2, -6.0, -6.2]
]
```

`P` 决定反馈误差如何分配到五个电机；`Kp` 和 `Ki` 是矩阵外的标量增益，不改变矩阵的耦合方向和稀疏结构。

### 3.3 零空间向量 n

上位机使用的单位化零空间向量为：

```text
n = [0.40395201, 0.39558015, 0.61216442, 0.37580693, 0.40541705]ᵀ
```

它近似满足关节映射的零空间条件。增加 `αn` 主要改变内部张力，不应显著改变四个关节角。

## 4. 固件角度控制

### 4.1 进入 degree 控制

degree 控制第一次生效时，固件执行：

1. 记录 `q_entry = q_fb`。
2. 记录 `x_entry = x_actual`。
3. 清除旧积分、滤波和有限差分状态。
4. 保存五路电机相对进入点的安全基准。

只要 degree 控制持续运行，后续发送新角度目标不会重新记录进入点，也不会自动清除积分。更改 `Ki` 数值会清除积分状态。

### 4.2 参考角有限差分

最终目标不会直接进入控制器。每个 10 ms 周期，每个关节的参考角最多变化：

```text
Δq_ref,max = 0.25° / cycle
```

即理想参考角速度上限约为 25°/s：

```text
q_ref(k+1) = q_ref(k) + clip(q_target - q_ref(k), -0.25°, +0.25°)
```

这样可以避免大角度命令瞬间变成很大的电机位移。

### 4.3 角度反馈滤波

磁编码器反馈经过两级一阶低通，当前系数为 `0.25`。滤波结果记为 `q_fb`，并计算反馈角速度供诊断使用。当前角度控制没有启用 D 项。

### 4.4 R 前馈

前馈使用参考角相对进入姿态的变化量：

```math
\Delta x_{ff} = c R(q_{ref}-q_{entry})
```

其中 `c=200 counts/mm`。

前馈不使用角度跟踪误差，也不使用未知的 `ΔF`。拟合残差 `e` 没有在每个控制周期重复注入，以免形成固定的持续位移偏置。

### 4.5 PI 角度反馈

角度误差为：

```math
e_q = q_{ref}-q_{fb}
```

P、I 两部分为：

```math
\Delta x_P = cK_pPe_q
```

```math
\Delta x_I = cK_iP\int e_qdt
```

当前上位机默认下发：

```text
Kp = 0.70
Ki = 0.02 1/s
```

固件自身上电初值仍较保守；正常从上位机点击 START 时，会下发界面中的 Kp、Ki。

积分规则：

- 仅当 `q_ref` 已到达最终请求目标后才积分，避免积分项对抗参考角斜坡。
- `|e_q| <= 0.2°` 时该关节不积分。
- 误差换向后，积分自然按相反符号累加，不需要额外“超过目标就减积分”的分支。
- 没有单独的积分状态上限。
- P+I 的五路输出采用统一比例缩放，使任一路不超过 2000 counts；统一缩放可保持五路向量方向。

### 4.6 任务空间投影

前馈和 PI 任务均投影到 `range(R)`：

```math
Q = RR^+
```

```math
\Delta x_{task}=Q(\Delta x_{ff}+\Delta x_P+\Delta x_I)
```

投影会去掉反馈矩阵中意外进入内部张力方向的分量。零空间预紧 `αn` 不参与该投影，而是在投影之后独立加入。

### 4.7 绝对电机目标与有限差分

最终绝对目标为：

```math
x_{requested}=x_{entry}+\Delta x_{task}+b
```

其中：

```math
b=\alpha_{counts}n
```

然后才进行电机空间有限差分：

```math
x_{cmd}=x_{actual}+clip(x_{requested}-x_{actual},-20,+20)
```

即每个 10 ms 周期、每个 M00～M04 最多移动 20 counts。

必须先形成绝对目标再有限差分。若把 `αn` 放在有限差分之后反复累加，会把固定预紧位置错误地变成持续速度命令，可能造成张力失控。

## 5. 零空间张力分配

拉力传感器在受拉时显示负数。分配器内部统一使用正拉力幅值：

```math
T_i=-F_{sensor,i}
```

当前正常工作范围为：

```text
5 N <= T_i <= 90 N
```

即传感器显示范围约为 `-5 N` 到 `-90 N`。

### 5.1 分解任务张力和内部张力

```math
\alpha_{measured}=\frac{n^TT}{n^Tn}
```

```math
f_{task}=T-\alpha_{measured}n
```

### 5.2 求可行 α 区间

对每根绳要求：

```math
f_{min}\le f_{task,i}+\alpha n_i\le f_{max}
```

因此：

```math
\alpha_{min}=\max_i\frac{f_{min}-f_{task,i}}{n_i}
```

```math
\alpha_{max}=\min_i\frac{f_{max}-f_{task,i}}{n_i}
```

选择最小可行预紧：

```math
\alpha_d=\max(0,\alpha_{min})
```

必须满足 `α_d <= α_max`。若不满足，表示当前关节任务产生的张力分布与上下限冲突，仅调整一个零空间自由度无法解决，上位机会停止零空间分配。

### 5.3 α 的离散调节

上位机每 100 ms 更新：

```text
α误差死区              = 0.25 N
比例换算                = 20 counts/N
单次最大变化            = 50 counts
α_counts 范围           = 0～7200 counts
b_i                     = round(α_counts * n_i)
```

五路偏置作为一个统一的 `αn` 向量下发，不再对松绳电机使用独立的快速收紧累加器。

## 6. 张力安全保护

### 6.1 正常张力分配

- 最松一路小于 5 N 时，分配器提高 `α`。
- 五路均满足范围时，保持或缓慢修正 `α`。
- 若 `α_min > α_max`，停止零空间分配并报告不可行。

### 6.2 过紧主动放松

任一路传感器达到或低于 `-90 N` 时：

1. 立即停止角度实验、线性实验、联合辨识、训练和其他命令生产者。
2. 清除零空间偏置。
3. 切换到直接电机模式。
4. 五个电机每 100 ms 同步向放松方向移动 200 counts。
5. 当五路传感器全部大于 `-70 N` 后停止电机并解除保护锁存。

这不是单纯冻结当前位置的 STOP，而是主动放松。若传感器失效、电机离线或达到电机位置下限仍未恢复，则停止并报告故障。

### 6.3 其他保护

- 五路张力数据缺失、无效或超过 1.5 s 未更新时停止零空间控制。
- J00～J03 磁编码器必须有效。
- M00～M04 必须在线。
- degree 模式电机位置相对进入点设有约 ±7200 counts 保护。
- 电机协议绝对位置限制约为 ±30719 counts。
- 自动实验中 J01 的目标和实测角度必须始终严格大于 0°。

## 7. 自动阶跃实验

默认设置：

```text
姿态数                  27
激励关节                J00～J03，逐关节测试
阶跃幅值                ±10°
重复次数                3
基线记录                2 s
稳定范围                ±1°
连续稳定                2 s
单响应超时              25 s
记录周期                100 ms
总试验数                27×4×2×3 = 648
```

默认目标覆盖：

```text
J00: -60° ～ 60°
J01:   1° ～ 60°
J02:   0° ～ 50°
J03: -10° ～ 100°
```

每组流程：到初始姿态并稳定 → 记录基线 → 下发阶跃 → 记录至稳定或超时 → 返回初始姿态 → 下一组。

输出：

- 独立原始 CSV：`run_data/continuous_records/`
- 阶跃汇总 CSV：`run_data/step_tests/`
- 指标包括上升时间、超调量、稳态误差、±1°稳定时间、交叉耦合、最低 J01 和五路最大张力。

## 9. 推荐操作顺序

1. 连接五路力传感器并确认无载零点。
2. 连接 Encoder/Servo 串口并确认 J00～J03 均为 `Valid=OK`。
3. 确认 M00～M04 在线且电机 ABS 与机械状态一致。
4. 小角度运行 degree 控制，先验证 `Kp=0.70`、`Ki=0.02` 的方向和稳定性。
5. 启用连续记录。
6. 先用一个姿态和较小目标验证安全保护，再运行自动实验。
7. 自动实验首次建议将重复次数设为 1，确认全流程无误后再恢复默认重复次数。

## 10. 当前控制器的边界

- 当前没有 D 项；需要基于阶跃末段噪声和速度估计质量再决定是否加入。
- `R` 是局部识别结果，跨大范围姿态可能变化，因此 27 姿态实验用于判断是否需要分段线性模型。
- 零空间只有一个自由度，无法修复所有由任务张力、摩擦、走线和回差造成的不可行张力分布。
- `ΔF` 未加入前馈；拉力只用于零空间预紧和安全保护，不是当前关节角主反馈量。
- 自动实验时间很长，应先使用较少频率、较少重复次数完成小规模验证。
