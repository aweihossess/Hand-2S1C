## 2. 系统与数据链路

控制系统由三条链路组成：

1. ESP32-S3 读取 J00-J03 磁编码器并提供关节角反馈。
2. ESP32-P4 以 10 ms 周期计算角度控制量，并给 M00-M04 下发绝对位置目标。
3. 上位机以 100 ms 周期记录角度、电机、拉力与控制状态，并计算零空间预紧坐标。

自动实验不依赖上位机界面逐点点击，而是直接按与上位机相同的协议向 COM6/COM7 发送目标、采集反馈和执行安全检查。这避免了人工发送时刻不均匀造成的正弦目标抖动，并保证每次实验生成独立 CSV。

## 3. 最终控制架构

### 3.1 变量定义

- `q_target`：最终请求关节角，4×1。
- `q_ref`：经过参考角限速后的关节角，4×1。
- `q_entry`：进入 degree 模式时的关节角，4×1。
- `q_fb`：滤波后的实际关节角，4×1。
- `x_entry`：进入 degree 模式时的五电机 ABS，5×1。
- `R`：前馈腱长/关节角矩阵，5×4，单位 mm/rad。
- `P`：反馈方向矩阵，5×4，单位 mm/rad。
- `Q = RR+`：将电机位移投影到关节任务空间的投影矩阵。
- `n`：单位化零空间向量，5×1。
- `alpha`：零空间预紧坐标。
- `c = 200 counts/mm`：长度到电机计数的比例。

控制器将前馈、PI 反馈和零空间预紧明确分开：

```text
Δx_ff = c R (q_ref - q_entry)
e_q = q_ref - q_fb
Δx_PI = c P [Kp e_q + Ki integral(e_q dt)]
Δx_task = (R R+) (Δx_ff + Δx_PI)
x_requested = x_entry + Δx_task + alpha n
x_cmd = x_actual + clip(x_requested - x_actual, -20, +20)
```

这里没有使用未知的张力变化 `ΔF` 做前馈。拉力只参与零空间预紧计算和安全保护。

### 3.2 为什么要做任务投影

`P` 的列给出四个关节误差在五电机空间中的作用方向。由于五电机控制四关节，电机空间还包含一个内部张力自由度。将前馈和 PI 项乘以 `Q = RR+`，可以去除这些任务项误入零空间的分量，避免角度误差持续改变内部预紧。

零空间项 `alpha n` 必须在任务投影后加入，并且必须先形成绝对目标，再执行有限差分。如果把固定偏置在有限差分之后反复累加，它会从“位置偏置”错误变成“持续速度命令”，造成张力不断上升。

### 3.3 积分逻辑

- 仅在 `q_ref` 已到达最终目标后积分，避免积分项对抗参考轨迹。
- 单关节误差绝对值不超过 0.2° 时不积分。
- 误差越过目标后符号自然反向，因此积分自然减小，不需要额外的“超过目标就手动减积分”分支。
- 发送新目标不会清空积分；修改 Ki 时清空积分状态。
- 五路 PI 输出按统一比例缩放，使任一路不超过 ±2000 counts，同时保持五路向量方向。

## 5. 自动调参方法

### 5.1 PI 搜索

共汇总 21 组 Kp/Ki 候选，使用阶跃与正弦的联合指标评分。评分同时考虑：

- 阶跃 RMSE、稳态误差、±1°稳定时间和有效超调；
- 正弦 RMSE、幅值比、相位滞后和非激励关节耦合；
- 五路最大张力和安全中止情况。

最低综合评分点为 `Kp=0.70, Ki=0.02 1/s`。Ki 继续增大时，高频相位滞后没有稳定下降，部分候选反而增加阶跃误差和张力峰值。因此当前瓶颈不是“积分太小”，而是系统延迟、参考/电机限速、腱绳弹性及反馈滤波共同形成的动态带宽限制。

### 5.2 矩阵搜索

矩阵优化分为两条互不混淆的路径：

1. 改变 R 的混合比例，验证前馈模型是否需要替换。
2. 改变 P 的混合比例，验证反馈误差的五电机分配方向。

结果是 R 改动只带来很小的阶跃变化并使正弦相位变差；P 的 25% 混合取得最小综合评分。这说明反馈方向确实可局部优化，但静态矩阵不能消除频率相关动态延迟。

## 7. 广域测试中止与安全结论

计划从局部三姿态扩展到 27 个更广姿态。首次尝试移动到 `[9,15,30,0]°` 时，M02 张力在约 3.2 s 内由 24.6 N 快速上升到 39.5 N，并在下一采样达到 40 N 主机停止线。实验立即停止，后续广域点没有执行。

![广域姿态安全中止](../output/control_autotune_20260719/04_broad_pose_abort.png)

该事件说明：

1. 停止不是零空间偏置造成的，因为当时五路 `tensionbias=0`。
2. 局部 R/P 在大姿态变化时不能保证任务张力可行。
3. 27 姿态不能用“从一个姿态直接跳到下一个姿态”的方式执行。
4. 后续应使用张力可行域引导的渐进路径：单次姿态增量不超过约 2°，实测任一路超过 35 N 即回退，再决定是否继续。

本轮没有为了“完成数量”绕过安全停止，这是正确的工程选择。

## 8. 零空间张力与安全机制

拉力传感器受拉时显示负值，控制内部统一使用正拉力幅值 `T_i = -F_sensor,i`。零空间分配先将实际张力分解为任务张力和内部张力：

```text
alpha_measured = (n^T T) / (n^T n)
f_task = T - alpha_measured n
```

再由每一路上下限求共同可行的 alpha 区间：

```text
alpha_min = max_i [(f_min - f_task,i) / n_i]
alpha_max = min_i [(f_max - f_task,i) / n_i]
alpha_d = max(0, alpha_min), and alpha_d <= alpha_max
```

当 `alpha_min > alpha_max` 时，说明当前关节任务与张力上下限冲突，单个零空间自由度无法解决，应停止分配、缩小任务或改变姿态，而不是继续拉紧某一路。

本轮自动调参额外使用 40 N 主机停止线，目的是在未知广域姿态下保守采集。产品运行时的张力分配范围和主动放松阈值应由机械强度实验单独标定，不能把本轮 40 N 试验线误当作最终机械额定值。

## 11. 最终工程判断

### 已经可以使用的部分

- 在已验证的三个局部姿态附近，`Kp=0.70, Ki=0.02` 可以作为后续实验起点。
- 1° 内不计超调时，阶跃超调问题已经很小。
- 自动实验、独立 CSV、指标计算和安全中止链路均已工作。
- P 的 25% 局部混合有实测收益，可以继续在安全局部区间验证。

### 不能直接宣称完成的部分

- 不能宣称 27 姿态全工作空间验证完成。
- 不能宣称 P blend=0.25 已经是全局最优矩阵。
- 不能用继续增加 Ki 的方式补偿 0.20 Hz 的 108° 相位滞后。
- 不能把当前 R 当作跨全工作空间不变的精确模型。

### 下一阶段优先级

1. **J02 局部重辨识：** 固定其他列，只校正 P 的 J02 列，目标是把稳态误差从约 1.9° 降到 1° 内。
2. **动态补偿：** 增加目标角速度前馈或相位超前环节，先在 0.10/0.20 Hz 验证；若使用 D 项，角速度必须低通且从很小增益开始。
3. **安全姿态扩展：** 使用不超过 2° 的路径增量，任一路超过 35 N 即回退，逐步建立张力可行域。
4. **分段模型：** 当安全姿态点足够后，按姿态区域拟合 R/P，并在区域间插值，而不是用单一常矩阵覆盖全空间。
5. **固件一致性：** 经用户确认后再烧录最终默认参数；烧录前断开 COM6，烧录后查询 Kp/Ki/R/P blend，避免上位机显示值与板上运行值不一致。

运行顺序：

1. 确认五路拉力零点、J00-J03 均为 Valid=OK、M00-M04 在线。
2. 重启上位机以加载最新默认值，连接 COM6/COM7。
3. 先在 `[10,10,20,10]°` 附近做 ±5° 小阶跃并开启独立连续记录。
4. 确认峰值张力、角度方向和停止逻辑正常后，再逐步扩展姿态。
5. 未完成广域验证前，不把局部 P 混合固化为全局上电默认。

本轮任务的最终成果不是一个“在所有姿态都已最优”的控制器，而是一套**可运行、可记录、可自动调参、能在危险趋势出现时停止，并且已经在三个局部姿态获得定量验证**的控制与实验平台。
