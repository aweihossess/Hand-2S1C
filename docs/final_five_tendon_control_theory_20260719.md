# 五腱绳四自由度手指控制理论与最终实现说明

版本日期：2026-07-19

代码分支：`codex/five-tendon`
控制器定位：当前实验平台的最终可复现实验版本

## 摘要

系统使用 5 个腱绳电机控制 4 个关节角，属于冗余驱动系统。最终控制器由参考轨迹限速、矩阵前馈、PI 角度反馈、任务空间投影、零空间预紧和电机空间有限差分组成。角度主环运行在 ESP32-P4，力传感器由上位机读取并用于零空间张力分配和安全保护。

最终默认参数为：

| 参数 | 最终值 |
|---|---:|
| 控制周期 | 10 ms |
| 参考角最大变化 | 0.25 deg/cycle |
| 电机有限差分 | 80 counts/cycle |
| Kp | 0.70 |
| Ki | 0.02 1/s |
| R 前馈混合 rblend | 0.00 |
| P 反馈混合 pblend | 0.25 |
| PI 五路统一输出上限 | 2000 counts |
| 积分死区 | 0.20 deg |
| 实验张力范围 | 5 - 80 N |
| 上位机硬放松触发 | 90 N |

## 1. 系统结构

控制数据链如下：

```text
最终目标角 q_target
        |
        v
参考角限速 q_ref -------------------------+
        |                                  |
        +--> R 前馈                        |
        |                                  v
实测角 q_fb --> PI 反馈 --> Q 任务投影 --> 任务电机位移
                                               |
力传感器 --> 零空间分配 --> alpha*n ---------+
                                               |
                                               v
                                     绝对电机请求 x_requested
                                               |
                                     80 counts 有限差分
                                               |
                                               v
                                          五路飞特舵机
```

ESP32-S3 提供 J00 - J03 磁编码器角度；ESP32-P4 以 10 ms 周期计算五路电机目标；上位机以约 100 ms 周期读取五路力传感器并更新统一零空间预紧坐标。

## 2. 变量与单位

| 符号 | 维度 | 含义 |
|---|---:|---|
| q_target | 4x1 | 最终请求关节角 |
| q_ref | 4x1 | 经过限速的参考角 |
| q_entry | 4x1 |进入 degree 控制时的关节角 |
| q_fb | 4x1 | 滤波后的反馈角 |
| x_entry | 5x1 | 进入 degree 控制时的电机 ABS |
| R | 5x4 | 前馈腱长映射，mm/rad |
| P | 5x4 | 反馈方向矩阵，mm/rad |
| Q | 5x5 | 任务空间投影 R R+ |
| n | 5x1 | 单位零空间向量 |
| alpha | 标量 | 内部张力坐标 |
| c | 标量 | 200 counts/mm |

所有矩阵运算中的关节角均换算为弧度。

## 3. 最终矩阵

### 3.1 前馈矩阵 R

```text
R = [
  [ 3.6109,  3.4232,  0.0000,  0.0000],
  [-2.9767,  4.0643,  0.0000,  0.0000],
  [-1.9980, -1.3476,  2.9110,  0.0000],
  [ 2.5066, -1.5569,  0.0000,  3.6078],
  [ 0.0000, -3.8985, -4.3955, -3.3443]
]
```

行对应 M00 - M04，列对应 J00 - J03。该矩阵由满足 J01 > 0 deg、四路角度有效、五路力传感器读数均不大于 0 N 的稳定端点进行鲁棒拟合。

### 3.2 反馈矩阵 P

```text
P_base = [
  [ 4.3,  5.9,  0.0,  0.0],
  [-4.3,  5.9,  0.0,  0.0],
  [-1.2, -3.0,  6.0,  0.0],
  [ 1.2, -3.0,  0.0,  4.8],
  [ 0.0, -6.2, -6.0, -6.2]
]
```

局部实验矩阵为：

```text
P_local = [
  [ 3.7902,  4.2846,  0.0000,  0.0000],
  [-2.7764,  4.3217,  0.0000,  0.0000],
  [-1.8163, -3.3031,  5.9482,  0.0000],
  [ 2.3439, -1.9732,  0.0000,  4.7259],
  [ 0.0000, -3.4184, -6.1187, -4.0970]
]
```

最终反馈方向使用：

```math
P_{eff}=0.75P_{base}+0.25P_{local}
```

前馈仍使用广域拟合矩阵 R，即 `rblend=0`；反馈使用 25% 局部矩阵，即 `pblend=0.25`。

### 3.3 零空间向量

```text
n = [0.40395201, 0.39558015, 0.61216442, 0.37580693, 0.40541705]^T
```

该向量已进行 L2 归一化，并近似满足任务映射的零空间条件。增加 `alpha*n` 主要改变内部共同张力，不应显著改变四个关节角。

## 4. 角度任务控制

### 4.1 参考轨迹有限增量

目标角不会直接跳变到控制器。每 10 ms 更新：

```math
q_{ref,k+1}=q_{ref,k}+clip(q_{target}-q_{ref,k},-0.25,+0.25)
```

该限制相当于约 25 deg/s 的参考角速度上限。

### 4.2 反馈滤波

四路磁编码器反馈经过两级一阶低通滤波，单级系数为 0.25。控制误差定义为：

```math
e_q=q_{ref}-q_{fb}
```

### 4.3 前馈与 PI

前馈项：

```math
delta_x_ff=cR(q_ref-q_entry)
```

比例项与积分项：

```math
delta_x_P=cK_pP_eff e_q
```

```math
delta_x_I=cK_iP_eff integral(e_q dt)
```

其中 `c=200 counts/mm`、`Kp=0.70`、`Ki=0.02 1/s`。

积分只在 `q_ref` 到达最终目标后启用；误差绝对值不超过 0.20 deg 时不积分。误差换向后积分自然反向累积。改变 Ki 时清除积分状态，连续发送新的角度目标不会自动清除积分。

### 4.4 任务空间投影

定义：

```math
Q=RR^+
```

前馈与 PI 统一投影到 `range(R)`：

```math
delta_x_task=Q(delta_x_ff+delta_x_P+delta_x_I)
```

这样可以去掉反馈矩阵中意外进入内部张力方向的分量。PI 五路输出采用一个共同缩放系数，使任何一路均不超过 2000 counts，同时保持投影向量方向不变。

## 5. 零空间张力分配

力传感器受拉时输出负数，控制内部使用正拉力幅值：

```math
T_i=-F_{sensor,i}
```

测得的内部张力坐标和任务张力估计为：

```math
alpha_measured=(n^T T)/(n^T n)
```

```math
f_task=T-alpha_measured n
```

要求每根绳满足：

```math
T_min <= f_task,i + alpha n_i <= T_max
```

于是：

```math
alpha_min=max_i((T_min-f_task,i)/n_i)
```

```math
alpha_max=min_i((T_max-f_task,i)/n_i)
```

选择最小可行预紧：

```math
alpha_d=max(0,alpha_min),  alpha_d <= alpha_max
```

正常分配范围采用 `T_min=5 N`、`T_max=90 N`。上位机每 100 ms 更新一次 alpha，力误差死区为 0.25 N，换算增益为 20 counts/N，单次 alpha 最大变化为 50 counts，总坐标限制为 0 - 7200 counts。

零空间偏置必须在任务投影之后、有限差分之前加入：

```math
x_requested=x_entry+delta_x_task+alpha_counts n
```

若把偏置加在有限差分之后并逐周期累积，固定预紧位置会被错误地转换为持续速度命令，导致张力失控。

## 6. 电机空间有限差分

最终电机命令为：

```math
x_cmd=x_actual+clip(x_requested-x_actual,-80,+80)
```

限制作用于每个 10 ms 控制周期。求解器内部和 ControlTask 外层均设为 80 counts，防止某一级静默采用较小旧阈值。

80 counts 是当前数据支持的最佳默认值：它比 20/40/60 counts 提供更低的正弦跟踪误差和相位滞后，同时已完成的 FD80 阶跃和 J00/J01 十周期正弦中张力保持安全。该结论仍需在力传感器修复后完成 J02/J03 与广域姿态验证，不能表述为全工作空间数学最优值。

## 7. 安全边界

### 7.1 关节角范围

```text
J00: -60 to +60 deg
J01:   0 to +60 deg
J02:   0 to +50 deg
J03: -10 to +100 deg
```

自动实验还要求 J01 的目标和实测始终严格大于 0 deg。

### 7.2 张力保护

- 自动验证脚本：五路正拉力幅值要求处于 5 - 80 N；持续松绳、正号异常或超过 80 N 时停止实验。
- 上位机总保护：任一路达到 90 N 时，清除零空间偏置并驱动五路同步放松；当五路均低于 70 N 后停止主动放松。
- 力反馈超过 1.5 s 未更新、通道缺失或无效时停止零空间控制。

### 7.3 电机和编码器保护

- M00 - M04 必须在线；
- J00 - J03 编码器必须有效；
- degree 模式相对进入点设有电机 ABS 保护；
- 协议绝对位置限制约为 +/-30719 counts；
- 跟踪误差超过固件 sanity bound 时保持电机位置。

## 8. 控制状态与运行顺序

进入 degree 控制时记录 `q_entry` 与 `x_entry`，清除旧积分和滤波状态。后续目标在同一次 degree 会话中共享进入点和积分历史。建议运行顺序：

1. 确认五路力传感器无载接近 0 N，受拉为连续负值；
2. 确认 J00 - J03 均为 `Valid=OK`；
3. 确认 M00 - M04 在线；
4. 启动连续 CSV 记录；
5. 发送 `START` 和目标角；
6. 先做小幅阶跃，再做十周期正弦；
7. 出现力通道正号、大跳变或陈旧数据时立即停止。

## 9. 当前版本未采用的控制项

- 未使用力差 `delta_F` 作为主前馈，因为目标下发时未知；
- 未使用固定残差 e 逐周期注入，避免形成持续位置偏置；
- 未启用 D 项。现有数据的主要问题是 J02/J03 映射误差和低频偏差，而不是高频振荡；直接加入 D 会放大编码器量化噪声；
- 未采用五路独立松绳收紧器，预紧仅通过统一零空间坐标完成。

## 11. 结论

最终版采用“参考限速 + R 前馈 + 混合 P/PI 反馈 + Q 投影 + alpha*n 零空间预紧 + 80-counts 有限差分”。该结构明确分离关节任务与内部张力，避免了历史版本中零空间偏置逐周期累加导致的张力失控，并保留了可复现实验所需的保护和记录链路。
