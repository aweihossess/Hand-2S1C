# 2026-07-06 项目阶段总结

## 目标

本阶段围绕“五绳驱动手指”的上位机、力传感器、Encoder/Servo 控制板和训练数据采集流程展开。核心目标是：

- 搭建可实时读取 COM7 力传感器数据的上位机。
- 同时接入 Encoder/Servo 控制板，显示关节角度、电机位置、速度、load 等状态。
- 支持 `degree` 关节角控制和 `direct` 电机位置控制。
- 使用力传感器作为实验阶段的张力监督信号，完成预紧、采集和安全放松。
- 采集可用于后续前馈模型或张力估计模型训练的数据。

## 力传感器上位机

### 读取协议

力传感器使用 Modbus-RTU `03` 功能码读取保持寄存器。每个通道占 2 个寄存器，即 32 位有符号整数。

已确认：

- CH1 起始寄存器为 `0x0000`
- CH5 起始寄存器为 `0x0008`
- CH5 读取命令为 `01 03 00 08 00 02 45 C9`

### 零位与单位

力传感器使用软件零位：

```text
relative_value = raw_value - saved_zero
force_N = relative_value / 10
```

即：

```text
相对值 100 = 10 N
```

零位记录流程：

1. 松开电机。
2. 让力传感器处于桌面无拉力状态。
3. 点击“记录零位”。
4. 零位保存到 `desktop/config/force_sensor_zero.json`。
5. 下次打开上位机会自动加载该零位。

### 当前功能

- 实时读取 CH1-CH5。
- 显示每个通道当前值和相对力 N。
- 用图像显示 CH1-CH5 的相对力曲线。
- 支持记录零位、清除零位、设备去皮、取消去皮。
- 支持普通 CSV 导出。

主窗口点击 `Encoder / Servo` 会打开第二个界面。

当前功能：

- 数字表格显示 Encoder raw、mapped、degree、valid。

## 机械零位与 degree 控制

当前策略是：

```text
只使用固件/控制板中的机械零位
上位机不再保存或叠加主机端 zero_deg
```

也就是说：

```text

```

旧的 `desktop/config/encoder_zero.json` 已废弃。界面里的“固件机械零位/删除旧主机零点”按钮只用于清除旧主机角度零点文件，不再建立新的上位机相对零位。

## degree 控制框架

### 控制目标

`degree` 控制的目标是关节角度，不是电机位置。上位机发送：

```text
degree; j0 target_deg
degree; j1 target_deg
degree; j2 target_deg
degree; j3 target_deg
```

固件将关节目标角和实时磁编码器角度进行比较，并通过控制矩阵和前馈模型转换为 M00-M04 的电机输出。

### 五绳控制当前设定

当前五根绳的作用：

| 电机 | 当前角色 |
| --- | --- |
| M00 | 参与 J00/J01/J02/J03 相关控制与张力维护 |
| M01 | 参与 J00/J01/J02/J03 相关控制与张力维护 |
| M02 | 参与 J00/J01/J02/J03 相关控制与张力维护 |
| M03 | 参与 J00/J01/J02/J03 相关控制与张力维护 |
| M04 | 回程/预紧绳，仅做张力维护，不参与 PID 和绳长前馈 |

重要历史决策：

- 曾经讨论和尝试过 M04 的反馈矩阵 Kp。
- 后来控制结构调整为 4+1 模式：M00-M03 负责关节控制，M04 只负责回程/预紧张力。
- 因此当前 M04 不参与 degree PID 和绳长前馈。

### 当前固件安全范围

当前 text degree 命令最终受固件限幅影响：

| Joint | 含义 | 当前可执行目标范围 |
| --- | --- | --- |
| J00 | MCP-AA | `-20° ~ 30°` |
| J01 | MCP-FE | `0° ~ 80°` |
| J02 | PIP-FE | 默认约 `0° ~ 88°`，若单关节标定成功则使用标定 `angleMax` |
| J03 | DIP-FE | 默认约 `0° ~ 93°`，若单关节标定成功则使用标定 `angleMax` |

注意：当前上位机训练范围中 J03 允许 `-45° ~ 45°`，但固件控制层会把 J03 的负目标裁剪到 `0°`。如果后续确实需要 J03 负角度数据，需要同步修改固件安全范围。

运行保护：

- J02/J03 的目标角与实际角误差超过 `30°` 会 hold 对应输出。
- MCP 五根相关电机 abs 超过 `±7200 counts` 会 hold 或 clamp。
- M00-M04 在 MCP degree 控制中每周期最大指令步进约为 `320 counts`。

## 训练数据采集

### 当前默认参数

| 参数 | 当前值 |
| --- | --- |
| 采样间隔 | `200 ms` |
| 目标周期 | `5.0 s` |

| 预紧超时 | `20 s` |

### 训练 CSV 内容

训练 CSV 会写入：

- 时间戳和本地时间。
- 当前自动目标模式、目标阶段、目标关节。
- J00-J20 的完整目标向量。
- CH1-CH5 原始值、相对值、换算 N。
- 按 M00-M04 映射后的绳张力。
- J00-J20 的 Encoder raw、mapped、degree、valid。
- M00-M21 的 Servo abs、hardware_abs、zero_offset、raw、speed、load、电压、温度、在线状态。
- 当前张力维护动作。
- `tension_bias_m00_counts` 到 `tension_bias_m04_counts`。

当前 `relative_deg` / `deg_rel` 是历史字段名，实际含义已经变成固件机械零位坐标下的 degree。

### 采集模式

| mode | 作用 |
| --- | --- |
| `coverage` | 每个目标周期改变一个关节，覆盖低位、高位、偏低、偏高、中位 |
| `single` | 单关节运动，其他关节回 0 附近 |
| `combo` | 组合姿态采集，用于观察关节耦合 |
| `roundtrip` | 单关节往返动态采集，用于覆盖摩擦、回差和方向相关性 |
| `step` | 一次发送 `[10, 20, 20, 35]`，用于看阶跃响应 |

## 自动预紧与张力维护

### 预紧目标

开始采集前，如果勾选“采集前自动预紧”，上位机会先把五根绳拉入力窗口。

当前力窗口：

```text
M00-M03: -150 N <= force_N <= -10 N
M04:     -20 N <= force_N <= -10 N
```

判断方式：

```text
force_N > -10 N      -> 绳太松，增加对应电机 tensionbias
force_N < tight_min  -> 绳太紧，减小对应电机 tensionbias
在窗口内             -> 不调整
```

### tensionbias

预紧和采集过程中的张力维护都通过固件的 `tensionbias` 机制完成。

它不是额外的第二套 bias，而是上位机发送给固件的张力偏置项。固件在 degree 输出基础上叠加该偏置。

当前限幅：

```text
M00-M04 tensionbias: -7200..7200 counts
```

M04 仅使用 tensionbias 维持回程/预紧张力，不参与 degree PID 和绳长前馈。

## Load 保护调整

早期训练采集使用统一的电机 load 保护：

```text
abs(load) > 800 -> stop
```

后来发现实验阶段已经使用力传感器做张力判断，电机 load 保护会干扰数据采集。因此当前改为：

```text
Load保护(abs) 默认留空
默认不因电机 load 自动停止
如需备用保护，可手动在界面填入阈值
```

如果手动填入阈值，代码仍会检查 M00-M04：

```text
abs(load) > Load保护阈值 -> 停止采集并发送 stop
```

## 安全放松模式

新增“安全放松”按钮，用于可行域实验前主动松绳。

当前逻辑：

1. 清除 `tensionbias`。
2. 发送 `start -> direct -> status`，确保下位机进入 direct 控制。
3. 等待约 `0.6 s`。
4. 对仍低于 `-2 N` 的 M00-M04，每 `200 ms` 向负方向退 `200 counts`。
5. 如果所有 CH1-CH5 都满足 `force_N >= -2 N` 并连续保持 `3 s`，自动发送 `stop`。
6. 如果下位机返回 `MOTOR_TARGET rejected` 或 `MOTOR_TARGET pending`，上位机会重发 `start/direct`，暂停继续递减目标，避免目标数值空跑。

安全放松目标不是精准控制姿态，而是让绳子松下来，方便做手指运动可行域研究。

## 数据分析与建模思路

已经形成的建模思路：

- 力传感器数据是实验阶段监督标签，不计划在最终控制中长期使用。
- 未来控制希望依靠电机相对位置、速度、load 和历史状态判断预紧状态。
- 模型输入不应只用单帧数据，应包含最近约 `0.6~1.0 s` 的历史窗口。
- 需要同时考虑电机位置、速度、运动方向、load 和关节角度。
- 力传感器为正数的数据可视为松绳或异常状态，在部分分析中需要过滤。

已经创建/使用过的分析方向：

- 查看最新采集数据覆盖范围。
- 检查 J00/J01/J02 小、J03 大于 30° 的样本是否存在。
- 检查 M04 位置是否变化。
- 比较力传感器张力与电机 load 的关系。
- 用历史窗口拟合/预测绳张力，评估 MAE 和 RMSE。
- 生成类似人手收拢的 J01/J02/J03 轨迹，其中 PIP 和 DIP 存在耦合关系。

## 当前重要注意事项

1. `J3:-45:45` 是上位机采集目标范围，但固件会把 J03 负目标裁剪为 0；如果需要真实负角度，必须修改固件限幅。
2. 当前默认不使用电机 load 停机保护，主要依靠力传感器张力窗口。
3. M04 是回程/预紧绳，不参与 degree PID 和绳长前馈。
4. 如果某根绳越预紧越松，需要把对应 `预紧步进` 改成负数。
5. 如果目标没到但力传感器读数越来越负，说明可能是机构/张力受限，不应简单继续加 Kp。
6. 如果目标没到且力接近 0 或变正，说明绳子可能松了，degree 输出没有有效传力。
7. 如果电机 Abs 没动，应优先检查模式是否为 degree/direct、下位机是否拒收命令、是否已发送 start。
