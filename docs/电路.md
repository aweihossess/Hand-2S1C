## 1. 上位机可直接操作的点（运行时）

| 接口/变量 | 你能怎么动 | 直接影响 |
|---|---|---|
| `CMD_START / CMD_STOP / CMD_RESET` | 切换控制使能、复位状态机 | 整机是否输出控制命令、故障状态是否清零 |
| `CMD_ANGLE_CTRL.target_deg[21]` | 改 21 路关节目标角 | 关节闭环目标、动作轨迹 |
| `CMD_MOTOR_POS.motor_raw_single_turn[22]` | 改 22 路直控单圈目标 | 直控模式下电机落点（会做最近圈映射） |
| `CMD_MOTOR_POS_SWEEP.motor_sweep_single_turn[22]` | 连续改滑条值 | 直控扫动平滑性、跨 0/4095 连续性 |
| `CMD_MOTOR_POS_ABS.motor_abs_pos[22]` | 直接改多圈绝对位置 | 直控响应最直接，越界会被限幅 |
| `CMD_TENDON_GUARD.enabled[21]` | 逐关节开/关防反转 | 哪些关节参与 x1 保护 |
| `CMD_TENDON_GUARD.sign[21]` | 改边界方向（+1/-1） | x1 比较方向，方向错会导致保护逻辑反向 |
| `CMD_TENDON_GUARD.x1_abs[21]` | 改绝对位置边界 | release 时何处触发阻断 |
| `CMD_SENSOR_STREAM_MODE.mode` | 在 `0/1` 间切换 | `SENSOR` 上报数值的编码方式 |
| `CMD_CALIB_DATA.zero_encoder_raw[21]` | 更新零位参考值 | 编码器映射基准，影响角度零点与偏置 |

## 4. 你当前最值得动的 8 个点（按优先级）

1. `CMD_TENDON_GUARD.x1_abs[21]`：先把边界配置稳定下来。  
2. `AngleSolver.kTendonGuardReleaseMarginCounts`：给防反转留动态余量。  
3. `EncodersTask.xFrequency` + `CanTask.xFrequency`：先保磁编高频稳定。  
4. `TactileTask` 真实采样开关与周期：把触觉从测试链路变成运行链路。  
5. 触觉 summary CAN ID 段：先避开 `0x200` 冲突。  
6. `CMD_SENSOR_STREAM_MODE`：统一上位机解析模式。  
7. `SystemTask` 的 PID 参数：做闭环性能调优。  
8. `jointMap/motorMap`：硬件连线调整时同步修正映射。  

---

## 5. 一句话边界

你能“做手脚”的入口主要是三类：  
1. 上位机命令 payload。  
2. P4 求解与保护阈值。  
3. S3 采样频率与 CAN ID 规划。
